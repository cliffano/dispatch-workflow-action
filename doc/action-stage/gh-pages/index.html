Description

GitHub Action for dispatching workflows across repositories and waiting for completion

Inputs

| name | description | required | default | | --- | --- | --- | --- | | workflow |

Workflow file name or ID to dispatch, the workflow must have a workflow_dispatch trigger

| true | "" | | repos |

List of repositories in owner/repo format defined in a comma-separated string, the workflow is dispatched on all repositories in parallel

| true | "" | | github_token |

GitHub token with permission to dispatch and read workflow runs on all repositories

| true | "" | | ref |

Branch or tag containing the workflow to dispatch, default: the repository default branch

| false | "" | | inputs |

Workflow inputs defined in a JSON object string

| false | {} | | wait |

Whether to wait for the dispatched workflow runs to complete

| false | true | | poll_interval |

Number of seconds between workflow run status checks

| false | 30 |

Outputs

| name | description | | --- | --- | | run_urls |

JSON object of each repository and its dispatched workflow run URL

| | conclusions |

JSON object of each repository and its workflow run conclusion, the conclusion is empty when wait is false, or error when the workflow could not be dispatched or its run status could not be retrieved

|

Runs

This action is a composite action.

Usage

```yaml - uses: PROJECT@VERSION with: workflow: # Workflow file name or ID to dispatch, the workflow must have a workflow_dispatch trigger # # Required: true # Default: ""

repos:
# List of repositories in owner/repo format defined in a comma-separated string,
# the workflow is dispatched on all repositories in parallel
#
# Required: true
# Default: ""

github_token:
# GitHub token with permission to dispatch and read workflow runs on all repositories
#
# Required: true
# Default: ""

ref:
# Branch or tag containing the workflow to dispatch, default: the repository default branch
#
# Required: false
# Default: ""

inputs:
# Workflow inputs defined in a JSON object string
#
# Required: false
# Default: {}

wait:
# Whether to wait for the dispatched workflow runs to complete
#
# Required: false
# Default: true

poll_interval:
# Number of seconds between workflow run status checks
#
# Required: false
# Default: 30

```
